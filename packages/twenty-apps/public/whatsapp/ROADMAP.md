# Roadmap

This roadmap is directional and does not promise release dates.

## Foundation

- [x] Native Twenty workflow action
- [x] Meta WhatsApp Cloud API provider
- [x] Text messages
- [x] Approved template messages
- [x] Template header/body parameters
- [x] URL and quick-reply button parameters
- [x] Structured provider errors
- [x] Provider abstraction
- [x] Unit-test baseline

## Near term

- [ ] CI validation on every contribution
- [ ] Media/image/document messages
- [ ] Improved provider retry guidance
- [ ] Compatibility matrix for tested Twenty releases
- [ ] Example workflows and screenshots

## Messaging lifecycle

- [ ] Incoming webhook handling
- [ ] Delivery/read-status webhooks
- [ ] Incoming message workflow trigger
- [ ] Interactive messages and lists
- [ ] Location/contact message support

## Providers

- [x] Meta WhatsApp Cloud API
- [ ] Twilio WhatsApp
- [ ] 360dialog
- [ ] Gupshup

## Scale and administration

- [ ] Multiple sender/account configurations
- [ ] Provider selection per configured connection
- [ ] Integration test harness against a development Twenty instance
